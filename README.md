#  Baker's Percentage Calculator

> **Personal Tool & Archive:** A lightweight calculator designed to quickly compute dough formulas, hydration levels, and ingredient proportions based on Baker's Percentage.

---

## 📌 Features & Purpose

In baking, ingredients are measured relative to total flour weight (which is always **100%**). This tool simplifies the math for:

* 🌾 **Flour Base:** Automatically sets total flour as 100%.
* 💧 **Hydration Level:** Calculates exact water weight based on desired percentage.
* 🧂 **Ingredients:** Computes salt, yeast, and additional preferment/ingridient baker's percentages instantly.
